# Claude Code Project Context

## Project Overview

**@apso/cli** - The official Apso command-line interface for code generation and service scaffolding.

### Tech Stack
- **Framework**: Oclif (CLI framework by Heroku)
- **Language**: TypeScript
- **Templating**: Eta (embedded JavaScript templates)
- **Package**: Published to npm as `@apso/cli`

### Key Directories
- `src/commands/` - CLI command implementations
- `src/lib/` - Core library functions for code generation
- `src/autogen/` - Auto-generated type definitions
- `templates/` - Eta templates for code generation (if present)

### Commands

```bash
# Project
apso init              # Create a new project (or clone from platform)
apso generate          # Generate code from .apsorc schema
apso dev               # Start local dev server via Docker Compose

# Schema
apso migrate           # Test schema migrations locally (PGlite sandbox)
apso schema validate   # Validate local .apsorc
apso schema diff       # Diff local vs remote schema
apso schema push       # Push local schema to platform
apso schema pull       # Pull remote schema to local .apsorc

# Deployment
apso deploy            # Deploy to Apso platform
apso status            # Show service and build status
apso logs              # View build logs
apso open              # Open service dashboard in browser

# Authentication
apso login             # Authenticate with Apso platform
apso logout            # Sign out from Apso
apso whoami            # Display current user info

# Platform
apso link              # Link project to a platform service
apso unlink            # Remove platform link
apso projects          # List services in a workspace
apso config            # View or modify CLI configuration
```

## How Code Generation Works

1. **Schema Definition**: Users define their data model in `.apsorc` (JSON/JSONC)
2. **Generate Command**: `apso generate -l typescript` reads the schema
3. **Generator Pipeline**: Language-specific generator class (e.g. `TypeScriptGenerator`) renders Eta templates into entities, controllers, services, DTOs, modules
4. **Output**: Generated files are placed in `src/autogen/` of the target project

### Supported Languages
- TypeScript/NestJS (primary, fully implemented)
- Python/FastAPI (in development)
- Go/Gin (in development)
